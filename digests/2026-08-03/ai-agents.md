## 7. 用户反馈摘要

### 痛点

1. **Desktop 端回归严重**：v0.19.0 移除状态指示器（#73211）、`read_file` 误判二进制（#76886）、消息平台加载超时（#77048）集中于同一时间窗口，用户对桌面端稳定性产生疑虑。
2. **Windows 支持不足**：ACP 适配器挂起（#73403）、NSIS 安装器路径问题、登录启动缺失（#38640/#76897）反映 Windows 生态适配仍不完善。
3. **凭据管理脆弱**：openai-codex 旋转 token 重放（#70097）、ACP OAuth 过期丢弃凭据（#70292）表明 token 生命周期管理需要更健壮的刷新机制。
4. **工具链可诊断性不足**：`lifecycle_guard` 崩溃无友好提示（#76762）、`patch` 失败信息不清晰（已通过 PR #77024 修复中）、`execute_code` 失败无恢复指引（已通过 PR #77106 改善）。
5. **消息平台集成混乱**：Discord 重复回复（#31550）、Buzz 强制线程回复（#77112）、WhatsApp 环境变量未读取（#56767）反映多平台适配的一致性问题。

### 满意之处

- **Skill Graph 插件**（#50057）和 **i18n 注册感知**（#77115）获得积极关注，体现用户对可扩展性和国际化的重视。
